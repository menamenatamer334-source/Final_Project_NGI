# Explore. 🌍
### Discover the World, One Destination at a Time

**Explore.** is a travel and tourism website designed to inspire people to discover beautiful destinations around the world, explore different cultures, and learn about popular tourist attractions.

The website provides a simple and attractive interface where users can browse destinations and discover interesting information about each place.

This project was developed as the final project for the NGI training program (NGO).

## 🌐 Live Demo
(https://menamenatamer334-source.github.io/Final_Project_NGI/)

## ✨ Features

- **Home Page:** An attractive landing page introducing the website.
- **Popular Destinations:** Explore famous cities and destinations around the world.
- **Destination Information:** Discover details about each destination, including its continent, famous food, famous places, and language.
- **Interactive Navigation:** Easily navigate between different sections of the website.
- **Destination Slider:** Browse destinations using the Previous and Next buttons.
- **Responsive Design:** A user-friendly layout designed for different screen sizes.
